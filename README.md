# 歌曲 → 声波电动牙刷播放格式 转化程序

本地 Web 应用:上传**乐谱图片**或**音频文件**,自动识别音符(频率 + 时长),转化为声波电动牙刷电机可播放的 `(频率, 时长)` 序列,支持试听与导出 `.txt`。处理全程在本地完成,数据不上传。

对应需求规格说明书 v1.1(`歌曲转牙刷播放格式-需求规格说明.md`)。

---

## 快速启动

1. 安装 **Python 3.9+**(需包含 `numpy`、`Pillow`):

   ```bash
   pip install numpy Pillow
   ```

2. 启动服务:

   ```bash
   python run.py
   # 或双击 start.bat;自定义端口:python app/server.py 9000
   ```

3. 浏览器打开 **http://127.0.0.1:8765** 即可使用。

> 没有现成素材?页面提供「使用内置示例音频(小星星)」按钮,一键体验完整流程。

## 功能说明

| 模块 | 说明 |
| --- | --- |
| 双上传通道 | 左侧乐谱图片(PNG/JPG/PDF,≤20MB),右侧音频(WAV/MP3/FLAC/M4A,≤50MB),支持拖拽与点击 |
| 音频识别 | YIN 单音跟踪 + 短窗能量谷底 onset 检测(numpy 实现):同音高重复音符正确切分、自动估计 BPM、休止检测(音符间间隔输出为 (0, 时长) 事件,分辨率 5.8ms);WAV 直接解码,MP3/FLAC/M4A 检测到系统 ffmpeg 时自动转码 |
| 图片识别(MVP) | 简谱(数字 1-7 + 下划线 + 高/低音点,模板匹配);高音谱五线谱(谱线检测 + 音符头定位 + 音高映射);PDF 自动渲染每页后逐页识别(需 Poppler) |
| 频率映射 | 默认按 180–400Hz 电机窗口映射:区间内保持 → 等比整体变调 → 对数压缩,自动提示;可勾选「保持原音调」还原歌曲原始音调(输出可能超出电机窗口) |
| 时长量化 | 1/16 音符网格对齐,最小事件 0.03s 合并,首尾休止修剪 |
| 120s 控制 | 短曲按乐句补全 + 速度限幅 ±10% + 呼吸休止微调;长曲提速 +20% → 截取乐句边界 → 删除重复乐段 → 硬截断兜底 |
| 循环衔接 | 序列首尾无缝,可循环播放验证 |
| 试听播放 | Web Audio API 实时合成正弦波,8ms 淡入淡出,播放/暂停/停止/循环 + 进度条;可切换「转换后序列(电机模拟)」/「识别原旋律(未变调)」对比,确认识别质量 |
| 导出 | UTF-8 `.txt`,默认纯数据模式(每行 `(整数, 三位小数)`),可选项「包含元数据头」;文件名 `{歌曲名}_牙刷版.txt` |
| 高级设置 | 目标时长、频率窗口、BPM 覆盖、循环开关、保持原音调(默认关闭) |
| 状态反馈 | 上传中 → 识别中 → 转换中 → 完成/失败,友好中文错误提示,无静默失败 |

## 项目结构

```
app/
  server.py          # 本地 HTTP 服务(纯标准库)+ /api/convert
  models.py          # NoteEvent / PlayEvent / ConvertParams / ConvertResult
  converter/         # 频率映射、时长量化、休止处理、120s 控制、循环衔接(纯算法)
  recognition/       # audio.py(YIN 音高跟踪)/ image_omr.py(简谱 + 五线谱)
  exporter.py        # txt 导出
  ui/                # 原生 HTML/CSS/JS 前端
tests/               # 22 项单元测试 + 浏览器端到端脚本(work/e2e_check.js)
run.py / start.bat   # 启动入口
```

## 运行测试

```bash
python -m unittest discover -s tests -v
```

覆盖验收标准:2 分钟单旋律 → 120s、30s 补全、5 分钟裁剪、休止保留 `(0, d)`、纯数据格式、确定性、异常输入、简谱/五线谱识别、音频音高与休止识别。

## 已知限制(MVP)

- 图片识别为单声部 MVP:简谱依赖清晰数字,五线谱暂以四分音符时值为默认,不支持连音线/装饰音/多声部/和弦。
- PDF 乐谱需要系统安装 Poppler(提供 `pdftoppm`),或将 PDF 转成 PNG/JPG 后上传。
- 音频识别为 YIN 单音跟踪,带伴奏歌曲的主旋律提取(如 CREPE 深度学习)未集成。
- MP3/FLAC/M4A 需要系统安装 ffmpeg 并加入 PATH,否则请使用 WAV。
- 试听为可听模拟(正弦波),不驱动真实电机;后续可扩展蓝牙/USB 实时下发。
